'#Web Sitem'
HTML ve CSS kullanalarak sıfırdan geliştirilmiş kişisel portfolyo web sitesi.Bu projede sahip olduğım teknik yetkinlikleri,aldığım eğitimleri ,çalıştığım şirketlerin benim hakkımdaki düşünceleri ve sertifikaları dijital ortamda düzenli bir şekilde sergiliyorum.
Projenin amacı:
temel web geliştirme pratiklerini pekiştirmek.
alınan sertifikaları tek bir platform üzerinden potansiyel işverenlere ve ziyaretçilere sunmak.
Kullanılan Teknolojiler:
CSS:Görsel tasarım,düzen ve stillendirme işlemleri
GİTHUB: proje yönetimi ve versiyon kontrolü
HTML:Sayfanın yapısal iskeletinin oluşturulması
Özellikler:
Anasayfa,yazılımlar,sertifikalar,başarılar,hakkımda ve iletişim sekmeleri.
